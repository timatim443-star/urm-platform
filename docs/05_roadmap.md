# 05. Дальнейшая доработка

Что уже работает, что осталось и в каком порядке это делать. Каждый пункт — отдельная версия: её можно выпустить и при необходимости откатить, не трогая остальное.

## Сделано в 2.1.0

- вход по логину и паролю, пользователи и роли в базе, страница «12 Пользователи», смена своего пароля;
- проверка сессии раз в 5 минут, журнал `AUDIT`;

## Сделано в 2.3.0

- сессия переживает обновление страницы (F5) и перезапуск сервера, 4 часа;
- общие учётки городов: много людей под одной учёткой; администратор — одно устройство;
- пароль без ограничения длины (только латиница), без блокировки после ошибок;
- миграции базы платформы с откатом, команды `doctor`, `migrate`, `users`;
- надписи и подсказки включаются и выключаются в `.env`;
- новая шкала цветов тепловой карты «Лаборатория × материал»;
- автотесты и сборка образа в GitHub Actions.

## Что должно измениться в данных (не в платформе)

Из письма от 28.09.2026 (Абылай А.А.) следуют изменения в расчёте витрин. Это зона Digital Direction и runner, а не платформы:

1. **Единицы измерения 1С.** Часть позиций выдаётся не в штуках (одна выдача предметных стёкол — 50 штук). Номенклатуру 1С переводят в штуки. До этого доля использования по таким материалам искажена.
2. **Количество контейнеров в ЛИС.** Нужно учитывать `BiomaterialSamplingGroup.containers_count`: две пробирки на один штрихкод — это 2, а не 1. SQL приложен к письму.
3. **Инвентаризация партнёров** даст фактические остатки. Их можно будет загрузить как начальную точку для «Расчетной дельты*». Для этого понадобится новая витрина от DD и доработка страниц.

Когда DD опубликует витрины с этими изменениями, платформа подхватит их сама после ночного расчёта. Код менять не нужно, если не изменятся названия колонок.

## Как предлагать доработки

Каждая доработка оформляется отдельной задачей (issue) в репозитории: что нужно и зачем, пример (скриншот, город, заказчик). Затем отдельная ветка → pull request → проверки GitHub → версия в `CHANGELOG.md` → тег. Если версия оказалась неудачной, она откатывается одной командой (см. [04](04_ОБНОВЛЕНИЕ_И_ОТКАТ.md)).
