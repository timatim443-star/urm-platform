# УРМ — учёт расходных материалов

Веб-платформа для директоров и аналитиков. Она показывает сверку выдачи расходных материалов по 1С с их использованием по ЛИС: по городам, заказчикам (БИН), материалам и месяцам.

Данные берутся из витрин PostgreSQL `urm2`, которые Digital Direction обновляет каждую ночь. Платформа их только читает. Записывает она лишь маппинг (по кнопке) и пользователей.

**Что внутри:**

- страницы 00–09 из генератора отчётов УРМ v4 — тот же дизайн и те же расчёты. Главная страница — 00 Методика;
- 11 Маппинг: справочники ЛИС ↔ 1С с правкой прямо в базе и проверками;
- 12 Пользователи: учётные записи и роли в базе;
- три роли: город (только свои данные), все города, администратор;
- страницы открываются меньше чем за секунду: данные один раз после ночного обновления копируются в быстрый снимок.

## Быстрый старт (Docker)

```bash
git clone <адрес репозитория> urm && cd urm
cp .env.example .env          # вписать адрес базы и логины/пароли
docker compose up -d --build  # собрать и запустить
docker compose exec urm python tools/doctor.py   # проверить, что всё подключено
```

Интерфейс откроется на `http://<сервер>:8501`. Перед первым входом нужно один раз подготовить базу и завести администратора — это шаги 3–4 в [docs/01_РАЗВЕРТЫВАНИЕ.md](docs/01_РАЗВЕРТЫВАНИЕ.md).

## Пробный запуск на своём компьютере (без Docker)

```bash
pip install -r requirements.txt
./run_demo.sh            # Linux/macOS;  на Windows — двойной клик по run_demo.bat
```

Скрипт спросит логин и пароль к базе и запустит платформу в **тестовом режиме**: без входа, видно всё. Для пользователей этот режим не подходит.
